Spectrum Mode

Audio visualiser using the onboard electret microphone. Each tube displays 4 frequency bars (24 bands total, 280–3800 Hz log-spaced, bass left → treble right).

Amplitude-modulated LED ring colour in Spectrum mode Bar colour for the LCD spectrum display

While the room is quiet, click Capture Baseline to snapshot the hardware noise floor. The baseline is saved to flash and applied instantly on every boot, eliminating the startup bar-dance and persistent interference lines.

⚠️ Switch away from Spectrum mode before capturing. In Spectrum mode the mic is continuously processing live audio — this interferes with baseline capture and will cause a timeout error. Switch to Clock or any other mode first, then capture.

Weather

Periodic weather data fetch. Disabling frees ~8 KB RAM and stops HTTPS calls. Restart required.

The clock will not fetch any online service. Push readings from your home-automation system to POST /api/weather with JSON, e.g. {"temp_c":15.3,"humidity":65,"condition":"Cloudy","icon":"overcastClouds"}. Send temp_c or temp_f (only one). Icons: sun, fewClouds, overcastClouds, fog, rain, snow, squalls, thunderstorm (or send a WMO weather_code).

At least one panel must remain enabled.

DAC Output Test

      

        Inject a known signal on GPIO25 to measure idle noise without a firmware rebuild.
        Use with an oscilloscope or audio spectrum analyser on the amp output.
        Normal ↩ restores idle operation.
      

      

        
        
        
        
        
        
      

      

        
        
        
      

      

        Hi-Z: GPIO25 = high-impedance input, DAC powered off — maximum isolation from rail noise.
        Silence / DC: fresh DMA ring pre-filled with a constant level — same approach as Tone, no driver switching.
        Tone: fresh DMA ring pre-filled with phase-continuous sine — loops until Normal is pressed.
        Normal ↩: tears down the test channel, then restores idle silence (retries up to 300 ms for I2S hardware to settle).
      


      
      

      
Backlight PWM Test

      

        Change LEDC_TIMER_0 frequency (GPIO19 backlight) at runtime to find
        a setting that minimises DAC noise coupling through the shared 3.3 V rail.
        Changes are immediate. Restore resets to 50 kHz.

Static Snow

      

        Writes truly random RGB565 pixels to selected tubes every display tick
        (5 Hz).  Every pixel address receives an independent random level each
        frame — more thorough than the solid colour-cycle for uneven wear
        patterns.  Can run alongside the colour-cycle on different tubes.
