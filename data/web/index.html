Advanced Display

Panel correction settings for replacement screens. The LCD Brightness and Night Brightness sliders above apply uniformly to all tubes as a group; the individual trim below scales each tube within that baseline.

Calibration Test Screen
Shows a fixed pattern on the chosen tubes so you can judge the settings below by eye, next to a stock tube. Save to apply a change — the pattern updates right away. Stops by itself after 5 minutes.
Tubes:
Gamma Correction
Per-tube software midtone correction — 1.0 = no correction (zero overhead). Values above 1.0 darken midtones, increasing perceived contrast and color depth on panels with a flat native response. Try 1.3–1.8 for washed replacement panels. Above about 1.5 the dim tube-fill glow starts to fade — Shadow Lift below brings it back. Takes effect after Save.
Panel Profile
Profile selects the hardware gamma curve. VCOM (0–63) sets the AC driving voltage — higher values increase contrast and color depth. For ST7735S replacement panels (e.g. LH096NT-IF09W) start with Profile Vivid + VCOM 40, then tune: raise toward 60 if still washed, lower toward 25 if over-saturated. Changes take effect after Save.
Tube Profile (gamma) VCOM (0–63)
Color Inversion
Enable for any tube whose replacement screen shows a photo-negative image. Sends INVON immediately — no reboot needed.
Window Offset
Shift the pixel window to fix 1 px static at the right/bottom edge of replacement panels. ST7735S variants (e.g. LH096NT-IF09W) typically need Col +2 / Row +1.
Tube Col Row
Individual Brightness Trim
Scale each tube's pixels relative to the group LCD Brightness above. Use when one replacement panel is noticeably brighter or dimmer than the others (100 = no change).
Shadow Lift
Brightens dark pixels only — black stays black and bright digits are untouched. Use when tuning gamma/VCOM for a replacement panel costs you the dim tube-fill glow. Raise until the glow returns (0 = off).
Color Balance
Per-tube red / green / blue gain (100 = neutral). Use when a replacement panel has a tint — for example orange looking pink (lower blue) or yellow (lower green) next to a stock tube. Gains above 100 can clip that channel's brightest values.
Channel Curves
Per-tube red / green / blue gamma shaping (100 = neutral). Below 100 lifts that color's dark end, above 100 deepens it. Use when the dim steps of a replacement panel come out the wrong color — for example dim oranges looking purple (lower R and G, or raise B).
Black Pedestal
Raises what pure black shows as, per color (0 = off). Use when a replacement panel's black has a color cast — a blue-leaking black can be neutralized by adding a little red and green. Keep it small: it makes every black pixel on that tube slightly lighter.
Black Level
Pushes the darkest pixels to pure black, removing faint haze in dark areas of a replacement panel (0 = off). Keep it low — high values also swallow the dim tube-fill glow; use Shadow Lift to bring that back.

Firmware & Filesystem Update

Three ways to update this device, normally used in this order: 1. Firmware Update for a new firmware release (the common case), 2. Web UI Update to patch just the web interface without touching firmware, and 3. LittleFS Recovery as a last resort — a full filesystem reflash that erases everything and rebuilds from scratch.

Firmware Update (OTA)

Upload nextube-fw-ota.bin for over-the-air updates. Do not upload nextube-fw-full.bin — that is the full flash image for USB flashing only.

Web UI Update

Upload nextube-WebUI-v*.zip to apply only the changed web UI files. Your config, album images, and audio clips are never touched. No reboot required — changes are live instantly.

LittleFS Recovery

Flashes a complete nextube-littlefs-v*.bin image. Use only when the release notes explicitly require a full LittleFS reflash, or to recover a corrupted filesystem.

⚠️ This erases the entire LittleFS partition — all custom themes, album images, and audio files will be lost. Back up anything you want to keep using the LittleFS Files browser above.
Your settings (Wi-Fi, theme, brightness, etc.) are backed up to NVS automatically before the erase and restored on the next boot — no manual config backup needed for this step.

Backup & Restore

Download your current configuration to a file or restore it from a backup. Recommended before any LittleFS recovery flash.

Verify & Repair Stock Files

Checks every built-in file (sounds, fonts, icons, web UI) against what this firmware's own build actually shipped — catches a stale file the "Missing built-in files" banner above can't (it only checks whether a file exists, not whether its content is current). Only files found missing or different get re-downloaded, directly from the public repo at this device's own installed version — nothing else is touched, and nothing is ever downloaded speculatively.

🎬 WeatherLive Animation Rate

      

        Overrides WeatherLive's normal 10/20 Hz split with one fixed rate, for testing fluidity

🧵 Per-Task Stack Log

      

        Adds a stack high-water-mark line for every task (~25 lines) to the heap-telemetry
        log every 5 minutes — a smaller number next to a task means its stack has less
        margin left. Off by default (pure log noise once sizes are settled).
        Applied live, not persisted — resets to off on reboot.
      

      

        
        
      

    

    

      
📊 Task CPU — windowed average

      

        The System tab's live view is an instantaneous 250 ms sample — too noisy to fairly compare
        e.g. CPU usage before and after a settings change, or other comparisons. This averages over an arbitrary window instead: hit Start,
        let the device run normally for as long as you want (a rain scene, a soak test, whatever you're
        testing), then Get Result — repeatable without restarting the window.

        The 24 bands as the clock sees them: raw energy, noise floor, power after the dead zone, and what the tube shows.

DAC Output Test

      

        Inject a known signal on GPIO25 to measure idle noise without a firmware rebuild.
        Use with an oscilloscope or audio spectrum analyser on the amp output.
        Normal ↩ restores idle operation.
      

      

        
        
        
        
        
        
      

      

        
        
        
      

      

        Hi-Z: GPIO25 = high-impedance input, DAC powered off — maximum isolation from rail noise.
        Silence / DC: fresh DMA ring pre-filled with a constant level — same approach as Tone, no driver switching.
        Tone: fresh DMA ring pre-filled with phase-continuous sine — loops until Normal is pressed.
        Normal ↩: tears down the test channel, then restores idle silence (retries up to 300 ms for I2S hardware to settle).
      


      
      

      
Backlight PWM Test

      

        Change LEDC_TIMER_0 frequency (GPIO19 backlight) at runtime to find
        a setting that minimises DAC noise coupling through the shared 3.3 V rail.
        Changes are immediate. Restore resets to 50 kHz.
