# hotpatch_extras.txt — extra files to ship in the hotpatch ZIP
#
# The hotpatch always includes the complete data/web/ tree (index.html,
# version.txt).  Add entries here for any other changed assets that users
# should receive without a full LittleFS flash — themes, audio files, etc.
#
# Format: one path per line, relative to data/
# Lines starting with '#' and blank lines are ignored.
# config.json is always excluded even if listed here.
#
# Example entries:
#   images/themes/NixieOY/Numbers/5.jpg
#   images/themes/Formula1/AMPM/colon.jpg
#   audio/bell.mp3
#
# IMPORTANT: clear this file (leave only comments) after a full LittleFS
# flash release — the full flash already delivers every asset, so carrying
# old entries forward would bloat every subsequent hotpatch unnecessarily.
